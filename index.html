What you get

One client, every call site.

Replace axios, ky, ofetch, or raw fetch with one createFetch client — same queryFn shape on React, Vue, Nuxt, Next.js, Solid, Angular, Svelte, and SvelteKit. Migrate guide + CLI

TS

Return data, throw on failure, and pass the signal. That is the whole queryFn.

import { createFetch } from 'tanstack-fetch'
import { useQuery } from '@tanstack/react-query'

const api = createFetch({ baseUrl: 'https://api.example.com' })

useQuery({
  queryKey: ['users'],
  queryFn: ({ signal }) =>
    api.get<User[]>('/users', { signal }),
})

Why not axios?

Same job. Query-shaped answer.

axios, ky, and ofetch are solid HTTP clients. tanstack-fetch is shaped for the call site TanStack Query already expects.

  • Built for queryFn

    axios wraps responses. tanstack-fetch returns data, throws FetchError, and takes signal.

  • SSR cookies without glue

    ssr-forward ships cookie and auth headers from the incoming request. No hand-rolled adapter.

  • SSE that can authenticate

    EventSource cannot send Authorization. tanstack-fetch/sse uses fetch, so tokens work.

30-second start

Three lines into Query.

Install the package, create a client, pass signal. That is the whole setup.

app.ts
import { createFetch } from 'tanstack-fetch'
import { useQuery } from '@tanstack/react-query'

const api = createFetch({ baseUrl: '/api' })

useQuery({
  queryKey: ['users'],
  queryFn: ({ signal }) => api.get('/users', { signal }),
})

Features

Everything a queryFn client needs.

  • Query-shaped client

    Success returns data. Failure throws. Cancellation follows AbortSignal.

  • Typed FetchError

    status, code, and body are on the error. isFetchError narrows it.

  • Status handlers

    401, 403, 404, 429, other 4xx, and 5xx each have a hook.

  • Refresh on 401

    createRefreshTokenInterceptor: before (time) and after (first 401), single-flight.

  • Request DevTools

    setupDevtools(api) shows HTTP, SSE, SSR, and tRPC with attempts, timing, and caller file.

  • 4.81KB HTTP core

    The HTTP entry is the core. SSE, React, Vue, plugins, and tRPC are separate imports.

  • Plugins

    Named interceptors for retry, trace, and mocks. Eject one on a single call.

  • SSR forwarding

    Next.js and other server renders can forward cookies and auth headers.

  • SSE with auth

    Streams use fetch, so Authorization is a normal header. EventSource cannot send it.

  • Upload progress

    Multipart upload + download progress (onUploadProgress / onDownloadProgress).

  • tRPC link

    Router and Start can share the same token, plugins, and base client.

  • OpenAPI codegen

    Generate a typed client from an OpenAPI document with the bundled CLI.

  • React helpers

    FetchProvider, useFetch, and useSse when a component tree should share one client.

  • Vue & Nuxt helpers

    createFetchPlugin, useFetch, and useSse for Vue 3 and Nuxt apps.
