If you use TanStack Query, your `queryFn` wants: return data, throw on error, honor `AbortSignal`.

**tanstack-fetch 1.6.3** ships a migrate CLI: scan axios / ky / ofetch / raw fetch, apply safe rewrites, and scaffold React, Vue, Nuxt, or Next.js.

> Not an official TanStack package — shaped for the same Query API.

### Quick start

```bash
npx tanstack-fetch migrate --from all --dir ./src
npx tanstack-fetch migrate --from axios --framework react --write --no-provider
```

```ts
// before
queryFn: async ({ signal }) => {
  const res = await axios.get('/users', { signal, params: { page: 1 } })
  return res.data
}

// after
queryFn: ({ signal }) =>
  api.get<User[]>('/users', { signal, query: { page: 1 } })
```

| Flag | Meaning |
| --- | --- |
| `--from` | `axios` \| `ky` \| `ofetch` \| `fetch` \| `all` |
| `--framework` | `react` \| `vue` \| `nuxt` \| `nextjs` |
| `--provider` / `--no-provider` | React FetchProvider (default when asked: **no**) |
| `--write` | Safe transforms + scaffold |

`--write` is conservative — review reported findings (query params, interceptors, `res.ok`).
