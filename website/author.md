## About tanstack-fetch

`tanstack-fetch` is a lightweight alternative to axios/ky for apps using `@tanstack/react-query`. It returns data, throws typed `FetchError`s, and honors `AbortSignal` — matching the Query `queryFn` mental model.

Created and maintained by **Mohammad Garmabi**.
